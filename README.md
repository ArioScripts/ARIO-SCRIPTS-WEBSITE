# ⚡ ARIO SCRIPTS

> 🚀 A script database made for easy browsing, copying, and downloading.

Welcome to **ARIO SCRIPTS** — a growing collection of scripts organized in one place.

🌐 **Website:** https://arioscripthub.lovable.app

---

## ✨ Features

- 📚 Large script database
- 🔎 Easy script searching
- 🏷️ Script categories
- 📋 Copy scripts easily
- ⬇️ Download scripts
- 👤 User accounts
- 🔐 Secure authentication
- ⭐ Favorites / saved scripts
- 🛠️ Admin panel
- ➕ Add scripts through the admin panel
- 🗑️ Remove scripts through the admin panel
- 📊 Script information and statistics
- 📱 Mobile-friendly design
